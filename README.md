### 🌐 Why open source

China is **first-to-file**, rights are territorial, and foreign applicants must file through a locally-recorded agent. Good, plain-English public information is scarce — so I'm opening up the checklists, datasets and workflows I use every day. Star a repo if it helps, and open an issue if a figure needs updating.
